Hello from Flask Server ! 🚀

Votre application est en ligne. Voici les pages disponibles :

  • /consultation/ : la liste des clients
  • /fiche_client/1 : la fiche du client n°1 (avec ses commandes)
  • /fiche_nom/DUPONT : les clients qui s'appellent DUPONT
  • /recherche : rechercher un client par nom ou prénom
  • /enregistrer_client : enregistrer un nouveau client (admin)
  • /commandes/ : toutes les commandes
  • /statistiques/ : nombre de commandes et total par client
  • /lecture : une page protégée
  • /authentification : se connecter
  • /deconnexion : se déconnecter

API JSON

  • /api/clients : la liste des clients (/api/clients?q=dup pour filtrer)
  • /api/clients/2 : le client n°2
  • /clients_js : une page qui utilise l'API en JavaScript

Comptes de test : admin / password (tous les droits) et user / 12345 (consultation seulement).
